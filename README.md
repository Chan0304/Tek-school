# Tek-school — Technology Learning Platform

> Learning platform workspace for technology education, practical labs, and AI-enabled learning experiences.

## Executive overview
Tek-school is the code workspace for a technology learning initiative. The product direction is to make technical learning more practical through structured courses, guided exercises, and lab-based experiences. This README distinguishes intended product direction from functionality that has been verified in source code.

## Product goals
- Organise technical learning paths by skill and experience level.
- Combine structured lessons with practice and applied exercises.
- Provide a clear learner journey from enrolment through progress and completion.
- Support administration of learning content and learner operations.
- Explore AI-assisted learning or lab support where it is appropriate and validated.

## Proposed user groups
| User | Expected needs |
|---|---|
| Learner | Discover courses, access lessons, complete exercises, track progress |
| Instructor / mentor | Manage learning content, support learners, review outcomes |
| Administrator | Manage catalogues, cohorts, enrolments, and platform settings |
| Organisation / partner | Understand programme participation and progress reporting |

## Product modules to validate
Course catalogue, learning paths, learner dashboard, lesson delivery, quizzes and assessments, practical labs, progress tracking, instructor tools, administration, notifications, and reporting are candidate scope areas. Confirm implementation before describing any module as delivered.

## Product lifecycle
1. Validate learner personas, course catalogue, and programme outcomes.
2. Define learning paths, lesson formats, assessment rules, and completion criteria.
3. Design learner, instructor, and administrator journeys.
4. Implement course delivery and progress tracking in increments.
5. Validate content accuracy, accessibility, privacy, and assessment integrity.
6. Pilot with a defined learner cohort and capture feedback.
7. Release with support processes, content ownership, and learner communications.
